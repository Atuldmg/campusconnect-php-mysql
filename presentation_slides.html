Context & Problem Definition

The Challenge in Modern Campus Operations

Operational Breakdown
📁 Information Fragmentation

Lecture slides, circulars, and course schedules are scattered across third-party cloud drives, unvetted chat groups, and physical notice boards, resulting in missed student deadlines and communication gaps.

⏳ Manual Administrative Burden

Submitting assignments and managing deliverables over email causes lost attachments, lacks audit trails, and complicates teacher grading and structured student feedback delivery.

🚫 Zero Concurrency Controls

Campus event registrations and grievance handling lack centralized database constraints, resulting in double-bookings, capacity overruns, and unaddressed student issues.

System Architecture

High-Level Flow & Execution Pipeline

Flowchart Pipeline
🌐
1. Client Tier

Browser dispatches HTTP navigation or Fetch AJAX queries.

⚙️
2. Apache & PHP 8

Gateway enforces CSRF tokens and session role checks (require_role).

🗄️
3. Dual-Data Tier

Prepared PDO queries to MySQL or DOM parsing on XML & DTD.

📊
4. Response Output

Renders sanitized HTML views or dispatches JSON payloads.

CORE DECISION LOGIC:

Query Execution Status evaluates on server → On Success, renders interactive dashboard or JSON data → On Exception, triggers safe contextual validation alerts (403/422) without exposing database stack traces.

🎤 Speaker Note to Leader
"When a user interacts with CampusConnect, Apache routes requests to the PHP 8 runtime. The backend verifies CSRF tokens and role permissions, queries MySQL via PDO or parses XML via DOMDocument, and dispatches pre-rendered HTML or JSON."

Frontend Engineering & Tri-State Theme Engine

UI/UX Subsystem
☀️ Light Mode

Off-white surfaces (#f8fafc), high-contrast charcoal typography (#1e293b), and restrained blue accents. Optimized for well-lit lecture halls.

🌙 Dark Mode

Sleek slate and charcoal backgrounds (#0f172a, #1e293b) minimizing eye strain during nighttime study sessions.

🔄 System Auto Mode

Dynamically synchronizes with the operating system theme using window.matchMedia with instant Cross-Tab synchronization.

⚡ Zero Flash of Unstyled Theme (FOUC) Solution

A lightweight inline script runs synchronously in the HTML <head> before page render, reading localStorage and injecting the theme attribute before the browser paints the DOM, completely preventing white flashes.

Server Tier

Backend Architecture: Modular PHP 8 & Sessions

Core Engine
🧩 Modular Project Organization
  • config/: Centralized PDO database manager with seamless SQLite testing fallback.
  • includes/: Security guards (require_role()), CSRF tokens, and view components.
  • api/: RESTful endpoints returning structured JSON.
  • actions/: Self-contained transactional action handlers.
🔐 Cryptographic Session Lifecycle
  • Bcrypt Password Hashing: Utilizes password_hash() with salt.
  • Session Fixation Mitigation: Invokes session_regenerate_id(true) immediately upon successful authentication.
  • Cookie Hardening: HttpOnly and SameSite flags prevent JavaScript access to cookies.
🎤 Speaker Note to Leader
"Our backend follows clean modular PHP conventions. Password authentication relies on Bcrypt hashing, and we immediately regenerate the session ID upon sign-in to neutralize session fixation attacks."

Persistence Tier

Relational Database Architecture (MySQL InnoDB)

Normalized Schema
users

Credentials, role, department, roll number.

announcements

Circulars, categories, priority pinning.

resources

Study documents, file paths, size, MIME type.

assignments

Tasks, subjects, deadlines, max marks.

assignment_submissions

Uploads, notes, status, marks, feedback.

events

Symposiums, dates, venues, seat capacity.

event_registrations

Junction table linking students to booked events.

feedback

Grievances, resolution status, admin remarks.

RELATIONAL CONSTRAINTS: Composite unique constraint on UNIQUE (event_id, student_id) eliminates duplicate registrations. Cascading foreign keys preserve integrity across deletions.
🎤 Speaker Note to Leader
"Our database features 8 normalized tables with foreign key cascades and composite unique constraints. For instance, in event registrations, duplicate bookings are rejected at the database engine level."

Interactive Client Scripting

Asynchronous AJAX Search Engine (Fetch API + JSON)

Real-Time Search
🔍 The 3-Step Search Pipeline
  • 1. Keystroke Debounce: Client listens on input with a 300ms timer to prevent server flooding.
  • 2. Fetch API Dispatch: Asynchronously requests api/search.php?q=Web.
  • 3. Dynamic DOM Ingestion: Injects formatted cards into container in-place with zero page reload.
📦 Structured JSON Payload
{
  "status": "success",
  "count": 1,
  "data": [{
    "id": 1,
    "title": "AWT Lecture Notes & PDO Guide",
    "subject": "Web Technology",
    "formatted_size": "2.4 MB",
    "time_ago": "5 days ago"
  }]
}
🎤 Speaker Note to Leader
"Rather than reloading the whole page when searching for lecture notes, our JavaScript debounces the keystrokes and queries our JSON endpoint via the Fetch API, updating the results instantly."

Application Hardening

Enterprise Security Architecture (OWASP Protections)

Defense-in-Depth
💉 SQLi Elimination

100% Parameterized PDO Statements. Zero dynamic SQL concatenation ensures user input is strictly treated as query parameters.

🛡️ XSS Defense

Contextual HTML Escaping. All user-supplied output is passed through our e() helper utilizing htmlspecialchars().

🎫 CSRF Tokens

Cryptographic Session Tokens. Every state-changing form includes a secure token verified via validate_csrf().

🔑 Bcrypt Encryption

Passwords stored with cryptographic salt utilizing PHP's password_hash().

📁 Path Traversal Guards

download.php verifies canonical paths via realpath() inside the uploads folder.

🔒 Role Enforcement

Server-side access checks (require_role) strictly prevent privilege escalation.

🎤 Speaker Note to Leader
"Security was engineered into the foundation: prepared statements against SQL injection, strict HTML escaping against XSS, cryptographic CSRF tokens, and path traversal guards on file downloads."
